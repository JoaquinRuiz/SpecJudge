# Constitution: Team Task Manager

## Core Principles

### I. Simplicity First
Keep the design as simple as the problem allows. A single service and a single
relational database until there is measured reason to do otherwise.

### II. Tested Behavior
Every user-facing behavior MUST be covered by an automated test before it ships.

### III. No Silent Failures
When an operation cannot complete, the API MUST say why in terms the caller can
act on, never a generic 500.
